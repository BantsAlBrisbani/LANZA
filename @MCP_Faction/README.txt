Task Force Dingo - Arma 3 Faction Mod Source

Included:
- BLUFOR faction
- Infantry units
- Eden/Zeus visibility
- Group definitions
- Config-driven randomisation for vests, helmets, and face coverings

Build steps:
1. Open Arma 3 Tools.
2. Start Addon Builder.
3. Pack @TFD_Faction/addons/tfd_faction into tfd_faction.pbo.
4. Put the generated PBO in @TFD_Faction/addons.
5. Load @TFD_Faction in the Arma 3 launcher.

Notes:
- Custom icon/flag references were removed so the mod source works without .paa assets.
- Replace YourName in config.cpp and mod.cpp.
